1963-1981 Corvette Four Speed Shifter Linkage Adjustment

It is very important to know that the chrome shifter handle lower end must be engaged in the 1st and 2nd gate before inserting the locking guide to install the shifter.

Once you think you have the shifter in neutral position and go to insert the gate tool you should see the bottom of the chrome handle and the tool is inserted into the gates (looking at it upside down), on top of the end of the chrome handle. It is possible for the chrome handle to get out of the gate and if this happens you can still adjust the linkage but the shifter will not function.
