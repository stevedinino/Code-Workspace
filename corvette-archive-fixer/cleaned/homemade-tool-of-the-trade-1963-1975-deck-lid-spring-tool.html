Homemade Tool Of the Trade, 1963-1975 Deck Lid Spring Tool

Willcox

This tool was originally made years ago in our shop from old spare parts.  We decided that since the other reproduction tools are discontinued we would fab up a few for the website and see if they sell.  

The trick to using this is by using the deck lid top to open up the spring.  With the deck lid closed, you can reach around the back side and then insert the tool.  Then open the lid and the deck lid spring will catche on the tool and can then be removed from the car with ease. Once you have the spring out it’s a good idea to insert a bolt through it or some solid wire to make sure it doesn’t slip off.  I’ve never had one slip off.

If you are needing to make an adjustment to the spring tension, place the spring with the tool in place and move the deck lid until you can reach the desired tension.  If you are loading a new spring in the car then you’ll have to use either a floor jack or any other device to spread the spring so you can install the tool first.  I like to snag the spring on either the top ring or the second one to assure it will install correctly in the car.
